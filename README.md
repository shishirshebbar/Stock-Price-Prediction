# Stock Price Prediction using Linear and Ridge Regression

## About the Project

This project focuses on predicting stock prices using machine learning regression models. It utilizes **Linear Regression** and **Ridge Regression** to analyze historical stock data and forecast future prices. The goal of this project is to demonstrate how regression techniques can be applied to real-world financial datasets to model trends and predict stock performance.

---

## Features

- Stock price prediction using Linear and Ridge Regression models  
- Data preprocessing and visualization for better insights  
- Evaluation of model performance using metrics such as R² and RMSE  
- Comparison between Linear and Ridge Regression results  
- Easy-to-understand code structure for experimentation and learning  

---

## Tech Stack

- **Python** – Programming language for data analysis and modeling  
- **NumPy** – Numerical computations and array operations  
- **Pandas** – Data handling and preprocessing  
- **Matplotlib / Seaborn** – Data visualization  
- **Scikit-learn** – Machine learning models and evaluation metrics  
- **Jupyter Notebook** – For experimentation and visualization of results
